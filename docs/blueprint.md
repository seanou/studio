# **App Name**: Schola Ludus

## Core Features:

- Homepage Genially Embedding: Embed a Genially presentation on the homepage via URL.
- Genially History: Display a chronological history of previously embedded Genially presentations.
- Search Functionality: Enable users to search the history of Genially presentations by title or keywords. The tool uses AI to enhance the search feature with keyword extraction and semantic search.
- URL validation: Validates that a provided URL is a working Genially URL.

## Style Guidelines:

- Primary color: Blood Red (#8B0000) to create a strong visual impact.
- Background color: Gold (#FFD700), desaturated to provide a luxurious feel.
- Accent color: Gold (#FFD700) for interactive elements to catch the user's eye.
- Body and headline font: 'PT Sans', a humanist sans-serif font for headlines and body text.
- Use simple, outline-style icons for navigation and search to provide a clean user experience.
- Employ a clean, card-based layout for displaying Genially history, ensuring easy readability and navigation.
- Use subtle fade-in animations when loading Genially presentations to provide a smooth user experience.
